# Directory and platform logos

One mark for each of the 104 destinations in Obenan's public [directory roster](https://www.obenan.ai/directories-and-platforms/).
The file name is the roster key, so a deck, PDF or prompt can find a logo from
[`directories.json`](../../reference/directories/directories.json) without guessing.
The A to Z listing with these marks is
[`DIRECTORY_ROSTER.md`](../../reference/directories/DIRECTORY_ROSTER.md).

Provenance, reviewed 9 October 2026:

- 77 marks are byte-identical copies from the Obenan product asset library
  (Obenan's internal product repository, commit `b9725b2`). Most are 140 pixels square;
  the rest range from 68 to 4267 pixels and are kept at their original size.
- 5 marks from the same library were not square or not PNG (Alexa, Ford, GoYellow, NPPES,
  Toyota). Each was centered on a transparent square canvas at its original resolution,
  without resampling, so it does not stretch when shown in a square slot.
- 9 marks are byte-identical copies from the Obenan review-source asset library in the same
  commit, 128 or 142 pixels square.
- Five pairs share one file in the source libraries: Acompio and Business Branchenbuch,
  Busqueda Local and Ricercare Imprese (each pair is run by one publisher network), Citipages
  and Citysearch, OpenTable and OpenTable USA, and TomTom and TomTom EV.
- 13 destinations had no usable mark in either library. Their row names the public source;
  each was centered on a transparent 140 by 140 canvas without redrawing or recoloring.

Logos and names are trademarks of their owners. They are used here only to identify the
destinations Obenan's roster lists. Their presence does not mean a partnership, an
endorsement or coverage for a specific location.

## Use in sales material

- Use the exact file with the destination name as alt text or caption. Do not redraw,
  recolor, stretch or generate substitutes, and do not combine marks into a new emblem.
- Show a destination as part of the roster, not as a partner. Say which destinations apply
  to a prospect only after we confirm them for their locations.
- Inactive rows and shared-record rows keep the wording in the listing. Do not add
  per-platform claims about reviews, replies, questions or posts; we confirm those per
  platform for each business.

## Refresh

When the live roster changes, update the website source commit in `directories.json`, add or
remove the logo file, and regenerate this table, the listing and the JSON together. The
integrity test fails while any of them disagree.
