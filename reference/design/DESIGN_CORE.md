# Design core

This is the compact production contract for any rendered sales deliverable.

## Required inputs

- Deliverable type and audience.
- Language and form of address.
- Verified customer facts and their sources.
- Approved commercial terms, when relevant.
- Sender name and title.
- One concrete next step.

Stop when a required price, commitment or customer claim is missing. Do not design around a
truth gap.

## Visual constants

- Helvetica Neue, with Helvetica and Arial fallbacks.
- Ink `#0F0F14`, paper `#FFFFFF`, soft `#F7F7F7`, hairline `#E6E6E6`.
- Exactly one approved accent color.
- No decorative gradient, heavy shadow, gauge, doughnut or pie chart.
- One focal idea per page.
- Exact logo files from [BRAND_ASSET_LIBRARY.md](BRAND_ASSET_LIBRARY.md).

## Page grammar

Use only the components the story needs:

- outcome headline and short lede
- large verified number with scope label
- comparison bars on one scale
- evidence card with source and date
- quiet panel for context or limitation
- numbered plan or timeline
- investment card using authorized figures
- next-step ledger with owner and timing
- customer quote only when public use is approved

## Evidence grammar

Every figure should answer five questions:

1. What is being measured?
2. Over what period?
3. For which geography or portfolio?
4. From which source and capture date?
5. Is it measured, customer-provided, estimated or inferred?

Use `approximately` when the approved source is rounded. Never present an estimate as a
measured result.

## Hierarchy

1. Customer outcome or finding.
2. Primary proof object.
3. Interpretation in plain language.
4. Limitation or boundary.
5. Concrete next action.

If a page needs more than these layers, split it.

## Handover contract

Return:

- the editable source
- the rendered PDF when requested
- an evidence file or evidence section
- a short note listing any unverified item
- the exact local paths

Inspect every page. A successful export command is not visual verification.
